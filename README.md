#  n8n Automated Email Outreach Workflow

An automated email outreach system built using **n8n**, **Groq AI (GPT-OSS-120B)**, **Google Sheets**, and **Telegram**.

##  Features
- **Scheduled Triggers**: Runs automatically every week.
- **Dynamic Content Generation**: Uses AI via Groq to craft personalized, weekly motivational messages based on rotating themes.
- **Personalized Routing**: Employs conditional logic to send distinct tailored messages based on contact segments.
- **Instant Notifications**: Sends real-time execution summaries directly to Telegram.
- **Google Sheets Integration**: Fetches pending recipients dynamically from a spreadsheet database.

##  Tools & Technologies Used
- **n8n** (Workflow Automation)
- **Groq API / LangChain** (AI Message Generation)
- **Gmail API** (Automated Email Delivery)
- **Telegram Bot API** (Execution Tracking & Alerts)
- **Google Sheets API** (Data Source)
